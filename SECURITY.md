# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately through GitHub instead: open the [Security tab](https://github.com/usertour/usertour/security) and choose **Report a vulnerability**. Only the maintainers can see the report.

Please include:

- the affected component (server, web app, SDK or self-hosted image) and version
- steps to reproduce, or a proof of concept
- the impact, as you understand it

We will acknowledge your report, keep you updated while we work on a fix, and credit you in the advisory unless you would rather we did not.

## Supported versions

Fixes are released in the latest version. Self-hosted deployments should upgrade to the latest release to receive security fixes.

## Scope

This policy covers the code in this repository: the server, the web app, the SDK and the Docker image. For issues with Usertour Cloud, report through the same channel.
