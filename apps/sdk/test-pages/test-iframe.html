Targets inside frames

Selectors are resolved on this page first, then in every same-origin frame, nested ones included. Create a flow with a tooltip step (or a launcher, or an element condition), type one of the selectors below by hand, and check where it lands. The badge next to each frame shows whether this page can read it; Usertour can reach exactly the frames the page can.

What to try

Selector Expected
#page-button The button on this page. Nothing changed here.
[data-activity="plain"] #activity-submit Submit inside the same-origin frame; the tooltip sits under it and follows scrolling.
[data-activity="nested"] #activity-submit Submit inside the frame within a frame.
[data-activity="scaled"] #activity-submit Submit inside the frame drawn at 0.75×; the tooltip points at where it is drawn.
#activity-submit with 1st / 2nd / 3rd The plain, the nested and the scaled frame, in that order (the order of the frames on this page).
.hint-button with 1st / 2nd 1st is this page's Hint; 2nd is the plain frame's. The page comes first.
[data-activity="plain"] #activity-answer A text-input or text-fill condition on the input inside the frame.
[data-activity="cross-origin"] #activity-submit Not found: the frame is on another origin.
[data-activity="sandboxed"] #activity-submit Not found: the frame is sandboxed without allow-same-origin.
